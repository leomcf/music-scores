# Readme
A lilypond correction for L3 students in « EAD harmonie ». 
The assignment based on "I Could Write A Book" involves multiple analyses on the same core material. I had been "solving" this using variables within one lilypond file. This became too cumbersome to control. I thus decided to include all the music expressions in a separate file : I-could-write-a-book-defs.ily; 
the other files ending with "-keys" "-stage1", "-phrases" "-cpt" use the "defs" file as a dependency.
